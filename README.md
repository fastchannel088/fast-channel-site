# Fast Channel+ — Site Institucional

Site institucional estático da Fast Channel+, preparado para GitHub + Render.

## Arquivos
- `index.html` — página principal
- `style.css` — identidade visual azul e vermelha
- `script.js` — menu mobile e ano automático
- `logo.png` — logo oficial enviada para o projeto
- `assets/` — espaço para futuras imagens

## Render
Tipo recomendado: **Static Site**
- Branch: `main`
- Build Command: deixe vazio
- Publish Directory: `.`

Depois de conectar o repositório, novos pushes no branch configurado podem disparar novos deploys.


## Contato
O botão “Falar pelo WhatsApp” abre diretamente o WhatsApp para o número configurado no site.


## Ajuste visual
As tipografias secundárias foram ampliadas para melhorar a leitura sem deixar o layout pesado.
